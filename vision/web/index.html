02 / SESSION SETUP

나에게 맞는 입력 준비

한 번에 한 카메라, 한 손을 사용합니다.

1 카메라 연결

권한 미확인

장치명이 비어 있으면 권한을 먼저 허용한 뒤 목록을 다시 확인하세요.

iPhone 연속성 카메라가 보이지 않나요?

운영체제가 iPhone을 카메라 장치로 제공해야 목록에 표시됩니다. 연결·권한을 확인하고 목록을 새로고침하세요. 선택한 장치가 실패해도 다른 장치로 자동 전환하지 않습니다.

2 손 추적 모델

Python 처리

영상 수신과 추적 준비는 별도 상태입니다. 모델 오류가 나도 카메라 프리뷰는 유지됩니다.

3 사용할 손과 손가락

신체 기준의 손 선택
활성 손가락 여러 개 선택 가능

손·손가락 선택을 바꾸면 이전 세션을 닫고 새 세션에서 보정합니다. 이전 안내와 보정 결과도 초기화됩니다.

4 가상 건반 배치

연결 후 적용

영상은 비율을 유지해 전체 표시합니다. 건반 가이드는 화면상의 영역이며 실제 책상과의 정합을 뜻하지 않습니다.

5 자세 보정

기준 없음

손을 자연스럽게 둔 기준 자세를 먼저 저장하세요. 들림 수집에서는 해당 손가락만 편안하게 들고 유지합니다.

기준을 다시 저장하면 이 기준을 공유하는 모든 들림 보정이 무효화됩니다.

수집 대기

준비 1초 · 수집 3초 · 표본 부족 시 최대 5초

유효 0 / 입력 0서버 판정 대기

성공·실패는 Python의 품질 검사 결과로 결정됩니다.
