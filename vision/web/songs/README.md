# 데모 연습곡 차트

연습곡 가이드(웹 8번 카드)가 읽는 곡 차트(`pthoven-song-chart.v1`)다. 모두 [Mutopia Project](https://www.mutopiaproject.org/) MIDI를 저장소의 전처리기로 변환한 **연습용 편곡**이다. 원곡을 그대로 옮긴 것이 아니다. 발췌, 이조, 오른손 최상음 선택을 거쳤다.

| 파일 | 곡 | 구간·변환 | 음 | 라이선스 |
|---|---|---|---|---|
| `pleyel-rondo-m1-4.json` | I. J. Pleyel, *Rondo* ([Mutopia 191](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=191)) | 1~4마디, −7반음, 트랙 1 최상음 | 10음 · 도레미파 | Public Domain |
| `blumenthal-deux-anges-m1-4.json` | J. Blumenthal, *Les Deux Anges* ([Mutopia 611](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=611)) | 1~5마디 중 16 quarter까지(첫 프레이즈), −7반음 | 14음 · 도~솔 | Public Domain |
| `schumann-op68-03-m1-8.json` | R. Schumann, *Album für die Jugend* Op.68 No.3 ([Mutopia 651](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=651)) | 1~8마디, −12반음(옥타브만 이동) | 28음 · 도~솔 | CC BY-SA 3.0 |

- **슈만 곡(CC BY-SA 3.0):** 출처를 표시해야 하고, 이 차트를 고쳐 배포할 때도 같은 라이선스를 유지해야 한다. 화면의 출처 줄과 각 차트의 `attribution` 필드가 이 표시다.
- **음악적 검수:** 곡 메타데이터는 Mutopia 공식 목록에서 자동으로 가져왔고(`metadata_verified=false`), 사람이 음악적으로 검수하지 않았다. 데모 전에 선율과 리듬을 한 번 들어 보고 확인한다.
- 재생성 방법과 선정 기준은 [../../docs/2026-11-28-practice-guide.md](../../docs/2026-11-28-practice-guide.md)에 있다.
