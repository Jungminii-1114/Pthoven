4. 원본 검수 · 독립 정답 라벨

원본 프레임 시각

검수 화면에는 예측을 그리지 않습니다. 영상 시작 오프셋은 브라우저 기록 시각 기준 근사값입니다. 샘플 이미지는 정확한 입력 시각을 보존합니다. 접촉을 판독할 수 없는 구간은 ‘불명’으로 제외하세요.

F1은 물리 접촉이 독립적으로 확인된 라벨에 대해서만 해석하세요. 낮춘 속도에서 좋아진 결과를 원래 속도 성능으로 합치지 않습니다.
