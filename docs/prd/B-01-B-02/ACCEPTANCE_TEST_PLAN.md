# B-01·B-02 인수 테스트·실험 계획

## 1. 검증 수준과 판정 원칙

| 수준 | 확인할 수 있는 것 | 확인할 수 없는 것 |
|---|---|---|
| 수학/합성 fixture | 좌표·수치·상태 전이·경계·중복·버전 논리 | 실제 손 추적 정확도·물리 접촉 |
| 추정 관절 replay | 고정 원본에서 정책별 결과·누락 사유 | 영상에서 관절을 다시 추정했을 때의 성능 |
| 실제 영상 replay | 모델+판정의 전체 조건 비교 | 온라인 전송/출력 지연 |
| 실제 장치 온라인 | 권한·카메라·전송·발열·복구·사용성 | 별도 라벨 없는 타건 정확도 |
| 독립 라벨 평가 | 정의한 손가락 동작/가상 입력 지표 | 관측되지 않은 접촉·힘·교육 효과 |

테스트 기대값은 구현 결과를 다시 계산해 복사하지 않는다. 좌표는 손계산할 수 있는 점·독립 기준값으로, 상태는 수작업 정의한 시간 시퀀스로, 사용자 시험은 독립 검토 라벨로 검증한다. 현재까지 통과한 수나 실제 성능을 이 문서에 기재하지 않는다.

## 3. 실제 데이터 수집 프로토콜

### 3.1 수집 단위와 파일

- person_id는 익명 식별자, session_id는 날짜/배치/보정을 구분한다. 원본에 실제 이름을 파일명으로 넣지 않는다.
- trial_id마다 선택 손·손가락·시나리오·장치·영상 각도/조명·모델·정책·실제 FPS·보정 참조를 기록한다.
- 보정용 관측과 평가 시행을 분리한다. 한 시행에는 한 종류 동작을 넣는다.
- 준비 1초 → 수행 10초 → 손가락 복귀/유지 1초를 기본 기록 절차로 제안한다. 원본 t_ms와 cue 경계도 저장한다.
- 영상 저장 여부를 명시하고, 영상이 없으면 어떤 정답 라벨을 독립 검토할 수 없는지 기록한다.

### 3.2 시나리오와 라벨

| 시나리오 | 수행 | 필요한 라벨·관찰 |
|---|---|---|
| 정지 | 자연스러운 기준 자세 10초 | false candidate, 기준 드리프트, 추적/품질 상태 |
| 단일 동작 | 천천히 독립 들림→복귀 | 대상 finger, 들림·복귀 프레임, 관측 가능성 |
| 반복 | 느림/보통/빠름을 별도 시행 | 정확한 사건 시각·수·동작 간격, 끝 경계 미완료 |
| 끌기 | 바닥 근처 좌우 이동 | 주기 없는 이동, 잘못된 후보/음 |
| 이웃 손가락 | 대상은 정지, 이웃만 움직임 | 대상/이웃 finger, 연동 움직임 여부 |
| 손 전체 이동 | 손바닥째 이동/위치 복귀 | 기준 이동·재획득, 가짜 주기 |
| 가림 | 도중에 손가락/손을 가렸다 복구 | unknown 시작/끝, 가림 전후 주기 연결 여부 |
| 공중 동작 | 책상에 닿지 않고 유사 주기 | 독립적으로 확인 가능한 경우에만 공중 라벨. 기본 모델의 구조적 한계 별도 보고 |
| 표시 변경 | 정지 중/동작 중 flip/resize | 버전 갱신·중단·재개, 과거 좌표 오류 |
| 장치/조명 | 동일 시행을 조건별 재수집 | 처리 FPS·관절 누락·보정 실패·후보 지표 |

실제 접촉이 보이지 않는 상부 RGB 영상에서 검수자가 접촉 라벨을 확정하지 않는다. 독립 접촉 기준이 없는 경우 평가 대상은 ‘관측 가능한 들림/복귀 동작’ 또는 ‘의도한 가상 입력’이며, 물리 타건 탐지 정확도라고 명명하지 않는다.

### 3.3 최소 파일럿 규모 제안

1. 최소 5명·서로 다른 배치/보정을 가진 2세션을 수집한다. 가능하면 iPhone 연속성 카메라와 일반 웹캠을 모두 포함한다.
2. 각 지원 손가락에서 단일/반복 동작 각 20회 이상, 핵심 부정 시나리오는 각각 10초 이상 수집한다. 보정 불가 손가락도 실패 기록으로 포함한다.
3. 양손 지원을 제품 범위로 주장하려면 왼손/오른손 조건을 각각 수집한다. 한 손의 결과를 반대 손 검증으로 대체하지 않는다.
4. 빠른 파일럿은 검지·중지부터 시작하되 약지·엄지·소지의 미검증 사실을 남긴다. 다섯 손가락 현장 인수는 각 손가락 자료가 있을 때만 가능하다.
5. 참가자/세션 수와 시나리오 수는 서로 다른 숫자다. ‘약 20회’ 같은 기억값은 정확한 사건 라벨로 사용하지 않는다.

## 4. 정답 검수와 매칭

라벨에는 event_id, finger, reference_return_ms, uncertainty_ms, observation_validity, label_kind, reviewer_ref를 둔다. 접촉을 알 수 없으면 contact_label=unknown이다. 두 검수자가 일부 공통 구간을 검수하고 불일치 기준을 기록한다.

후보는 같은 finger·같은 시도에서 정답 사건과 일대일로 매칭한다. 초기 허용 시간 창은 ±150ms를 제안하고 검수 오차·제품 요구를 보고 고정한다. 가까운 예측을 여러 정답에 중복 매칭하지 않는다. 중복 후보는 추가 FP, 미매칭 정답은 FN이다. 허용 창을 결과를 본 뒤 넓히지 않는다.

평가 시각은 candidate `t_ms`다. `emitted_ms`는 출력 지연용이다. 시도 종료 뒤 복귀한 미완료 동작은 경계 정책으로 분리하고, 유리한 결과를 위해 다음 시행과 합산하지 않는다.

| 보정 성공률 | 전체 시도 중 유효 bundle 발급 비율. 보정 실패자/손가락 제외 금지 |
| 보정 시간 | 수집·재시도 포함 p50/p95, 실패 소요 시간 별도 |
| 관측 coverage | usable 시간/전체 시험 창 시간, 프레임 비율과 분리 |
| 출력 지연 | emitted_ms−t_ms p50/p95, 사건 수·누락·보류율 동시 보고 |
| 키 매핑 지연/오차 | 후보 프레임 조회·경계 보류·좌표 공간별 오류 |
| 자원/처리 | actual preview FPS, inference FPS, drop 수, queue peak, 메모리·온도 조건 |

분모 0은 null이다. 유효 관측만의 조건부 성능과 전체 시행 성능을 구분한다. 품질 보류로 어려운 구간을 제외하고 높은 F1만 보고하지 않는다. 독립 라벨이 있는 양성 동작의 전체 파이프라인 누락은 별도 end-to-end FN/실패로 남기며, 제품에서 unknown을 사용자 실수로 채점하는 것과 혼동하지 않는다.

공중 동작은 접촉 분리 한계 시험으로 별도 보고한다. 공중 동작을 제외한 지표의 범위를 제목에 명시하고, 공중 동작에서도 사건이 나오는 사실을 숨기지 않는다. 프로젝트가 접촉 구분을 제품 요구로 추가하면 현재 입력/모델만으로 가능한지 별도 go/no-go가 필요하다.

## 6. 비교 실험

| 실험 | 동일하게 유지 | 비교할 것 |
|---|---|---|
| A 고정 기준 vs 상대 기준 | 원본 관측·보정·시간·평가 라벨 | 드리프트·기준 재획득·FP/FN·보류 |
| B TIP 단독/관절 단독/결합 | 라벨·수집 조건·평가 창 | 결합의 누락/오검출 절충. 단독은 진단용 |
| C 관절 가중치 | 기본 데이터·특징 | 잡음 기반/끝 관절 강조/뿌리 강조, 손가락별 결과 |
| D 길이 검사 | 원본 관절 | 단순 길이 오차/공통 배율 분리/검사 비활성의 위험 |
| E 수집 시간 | 동일 사용자·조건·평가 분할 | 3초/5초, 보정 성공률·분리도·현장 시간 |

보정/튜닝용 시행과 최종 평가를 분리하고 사람/세션이 분할을 넘나들지 않게 한다. 정책 선택은 개발/검증 분할에서 끝내고 최종 평가를 반복해서 튜닝에 쓰지 않는다. 같은 원본 관측 재생과 새 영상 재추론의 비교 조건을 표시한다.

## 7. 초기 인수 게이트 제안

### 7.1 기능 게이트 — P0 필수

- INV 위반·세션 섞임·기대 음 대체·중복 게임 입력·오래된 버전 적용은 허용하지 않는다.
- 요구사항 추적표의 P0 합성·계약·통합 시험을 모두 통과한다. 알려진 물리 접촉 한계는 ‘해결’ 기대값이 아니라 제한 보존 시험으로 통과한다.
- 한 사용자의 보정/필터 오류가 다른 손가락·세션을 오염시키지 않는다.
- 10분 온라인 시험과 장치 재연결을 통과하고 종료 후 자원을 정리한다.

### 7.2 현장 목표 — 팀 검토 후 고정

초기 목표는 관측 가능한 들림/복귀의 held-out motion F1≥0.85, 정지 FP≤1/min, 최초 한 손가락 보정 성공률≥80%, PRD의 p95 지연·보정 시간 목표 충족을 제안한다. 이는 측정 결과나 확정 성능 보장이 아니다.

조건부 F1만으로 인수하지 않는다. 전체 시행 coverage·보정 실패·손가락별 결과·표본 수를 같이 보고, 작은 파일럿의 불확실성을 명시한다. 5분 정지 자료에서 FP 0개라고 오검출률 0을 보장하지 않는다. 목표를 바꾸면 결정 근거와 정책 버전을 기록한다.

### 7.3 미달 시 처리

- 보정 실패가 특정 손가락에 집중되면 해당 손가락을 제품 기본 활성에서 제외할 수 있으나 전체 지원 성공으로 표시하지 않는다.
- 렉/시간 문제라면 해상도·처리 FPS·큐를 조정하고 재측정한다. 이벤트 시각을 출력 시각으로 바꿔 개선으로 꾸미지 않는다.
- 길이 실패라면 원본 관측을 확인하고 특징/모델/가림 조건을 재검토한다. 임계값 완화만으로 인수를 통과시키지 않는다.
- 공중 동작 구분이 필수면 관측·제품 요구를 재설계한다. 합성 테스트를 추가하는 것만으로 해결됐다고 하지 않는다.
