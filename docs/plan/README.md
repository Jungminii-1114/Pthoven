# PTOVEN · 팀 설계 문서

프토벤은 일반 RGB 영상에서 책상 위 손가락 동작을 관찰하고, 가상 피아노 연습과 개인화된 코칭을 연결하는 서비스다. 이 문서 묶음은 팀이 전체 흐름·구현 책임·입출력·도구 동작·평가 방법을 같은 기준으로 이해하기 위한 설계 명세다.

구현 파일, 개발 완료율, 진행 상황은 이 문서의 범위에 포함하지 않는다. 문서에 나오는 함수·타입·스키마는 팀이 구현할 인터페이스의 설계 이름이며, 실제 코드의 존재 여부를 뜻하지 않는다.

## 문서 책임

- **Overall Plan:** 서비스 전체의 목적과 계층을 설명한다.
- **Big Node:** 세부 단계의 실행 순서·조건부 분기·반복·종료를 정의한다.
- **Small Node:** 단일 책임·필요한 내부 함수·입출력·실패 처리를 정의한다.
- **Tool:** Agent가 호출하는 인터페이스의 인자·반환·권한·부작용·재시도를 정의한다.
- **공통 계약:** 여러 문서가 공유하는 상태·데이터·시간·버전의 의미를 정의한다.
- **하네스:** 위 계약을 실행하고 기록·제어·평가하는 공통 구조를 정의한다.

Small Node 1개가 반드시 LLM 호출 1회 또는 그래프 라이브러리 노드 1개인 것은 아니다. 내부 보조 함수는 별도 Tiny Node로 세지 않는다. Tool과 Small Node도 1:1 대응하지 않는다.

## 서비스의 핵심 전제

1. 아이폰 연속성 카메라 또는 일반 웹캠이 위에서 책상과 손을 촬영한다.
2. 사용자는 노트북의 영상과 가상 건반을 보며 입력한다.
3. 아이패드·물리 피아노·마이크·책상 타격음·깊이 센서는 필수 장치가 아니다.
4. 기본 Agent는 텍스트·구조화 데이터를 받는다. 이미지는 CV가 처리한다.
5. 들림·복귀 동작 후보, 가상 게임 입력, 실제 물리 접촉은 구분한다.
6. 관측 불확실성은 오류 집계·코칭·보고서까지 보존한다.

계약과 예시 수치는 팀 검토를 위한 설계이며 실험 결과나 성능 보장이 아니다. 참조 구조와 차용 범위는 [참고 문서](references.md)에 설명한다.
