## 결정 기록 형식

각 결정은 decision_id, 질문, 선택지, 선택 근거, 적용 범위, policy/model/schema 버전, 영향받는 B/S/T ID, 확인 시나리오, 다시 검토할 조건을 남긴다. 단순 선호나 일반 벤치마크만으로 실제 촬영 성능·교육 효과를 확정하지 않는다.

## 우선 합의할 공통 원칙

- CV의 동작 후보와 물리 접촉은 구분한다.
- unknown을 사용자 오류나 숫자 0으로 바꾸지 않는다.
- 기본 코치는 구조화 데이터 기반이다.
- 읽기·변경 제안·실제 적용을 구분한다.
- 사용자 제어와 관측 보류가 모델 개입보다 우선한다.
- 지표와 최종 보고서는 같은 근거·실제 설정을 사용한다.
- 모델·런타임 선택을 업무 계약과 분리한다.
