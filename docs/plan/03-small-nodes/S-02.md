# S-02 · `estimate_hand_observation` — 손 관측과 시간 정보 추출

[세부 단계 목록](README.md) · [공통 반환 계약](../05-contracts/common-result.md) · [데이터 모델](../05-contracts/data-models.md)

## 1. 단일 책임과 경계

새 RGB 프레임을 손 관절·이미지 좌표·관측 시각·추적 진단으로 변환한다.

- 실행 성격: **CV 추론**
- 협업 담당: CV·웹
- 범위 제외: 책상 기준 mm 높이·물리 접촉·실제 음향을 출력하지 않는다.
- 상위 실행 경로: [Big Node 목록](../02-big-nodes/README.md)에서 관리한다.

## 2. 필요한 함수

진입점은 `estimate_hand_observation(request, context) -> NodeResult[ObservationBatch]`로 표현한다. 다음 함수는 내부 연산이며 Agent에 자동 공개되는 도구가 아니다.

| 내부 함수 | 입력 | 반환·책임 |
| --- | --- | --- |
| reject_duplicate_frame | 프레임 식별자·직전 상태 | 새 프레임 여부 |
| run_hand_landmarker | RGB 프레임·추적기 | 랜드마크·좌우 손 분류 |
| associate_hand_tracks | 이전·현재 손 관측 | 일시적 hand_id 또는 ambiguous |
| stamp_observation | 관측·시계·버전 | 시간·모델 식별자가 연결된 관측 |

## 3. 내부 처리 순서

1. 새 프레임에만 추론하고 추론 전후 시간을 구분한다.
2. 원본 이미지 좌표와 추정 3D 좌표를 함께 보존한다.
3. 좌우 손 분류와 손 연결 불확실성을 분리한다.
4. 손이 없으면 빈 hands와 no_hand를 반환하고 가짜 관절을 만들지 않는다.

## 4. 입력 계약

| 입력 타입 | 필수 의미 |
| --- | --- |
| FramePacket | 프레임 참조, 처리 시각, frame_id, 해상도 |
| SessionContext | clock_id, 손 선택, 추적기 설정·버전 |

세션·시도·시계·버전 참조는 [데이터 모델](../05-contracts/data-models.md)에 따른다. 범위가 맞지 않거나 필수 필드가 없으면 추정값으로 채우지 않는다.

## 5. 출력 계약

반환은 `NodeResult[ObservationBatch]`이며 `status`, `data`, `diagnostics`, `outcome` 네 키를 사용한다.

- `data` 타입: `ObservationBatch`
- 보존할 업무 필드: `frame_id, t_ms, clock_id, hands[], image_xy, world_landmarks, hand_association, diagnostics`
- `diagnostics`는 위 내부 함수명을 키로 실행·생략·실패와 근거를 기록한다.
- 데이터의 `null`, 빈 목록, unknown은 서로 다른 의미다. [공통 결과 계약](../05-contracts/common-result.md)의 규칙을 따른다.

## 6. 업무 결과와 오류

| outcome | 업무상 의미 |
| --- | --- |
| observed | 선택 손 관측 확보 |
| no_hand | 추론은 완료했으나 선택 손 없음 |
| ambiguous_identity | 관측 손 연결 불명확 |
| inference_failed | 추론 자체 실패 |

`outcome`은 `status`와 다른 축이다. 정상적으로 보류·빈 결과·정보 부족을 판단했으면 `status=success`일 수 있다. 실제 필수 처리 실패는 `status=error`로 구분하고, 안전한 일부 산출물이 있을 때만 `partial`을 사용한다. 예외를 잡았다는 이유로 성공으로 바꾸지 않는다.

재시도 가능성은 진단 힌트로 반환하며, 실제 재시도·다음 단계 선택은 하네스가 판단한다. 대기나 비동기 실행을 실행 오류와 혼동하지 않는다.

## 7. 검증 사례

- 새 프레임이 없으면 추론 횟수만 증가시키지 않는다.
- 손 없음과 추론 실패를 다른 상태로 반환한다.
- 미러링 표시를 바꿔도 좌표 정의가 누락되지 않는다.
- 두 손이 교차하면 확신 없는 손 ID를 이어 붙이지 않는다.

## 8. 설계 검토 항목

- 필드 타입·단위·버전과 유효 구간을 팀 계약에 맞춰 고정한다.
- 실행 한도·정책값은 [결정 항목](../07-decision-points.md)의 측정 절차로 선택한다.
- 근거·실행 상태·보류 사유가 다음 단계에서 소실되지 않는지 확인한다.

이 문서는 구현 책임과 검증 기준을 정의하며 현재 코드·완료율·구현 진척을 기록하지 않는다.
